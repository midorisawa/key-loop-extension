# キー変更・ループ

動画や音声の音の高さ（キー）を変えたり、決めた区間を繰り返し再生（ループ）したりできるChrome拡張機能です。
最低限の機能を、プログラミング初心者でも理解できる極めてシンプルな方法で実装しています。

## インストール方法

1. Chromeのアドレスバーに `chrome://extensions` と入力して開きます。
2. 画面右上にある「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」を押し、このフォルダーを選びます。
4. いつでもすぐに開けるよう、ブラウザ右上のパズルマークからこの拡張機能をツールバーに固定（ピン留め）しておくと便利です。

※ Chrome 116以降のバージョンが必要です。

## 使い方

1. Webページで動画や音声を再生した状態で、拡張機能のアイコンをクリックします。
2. キーを変えたいときは、「キー変更」のスイッチをオンにします。スライダーで上下12半音（±12）まで調整でき、動かしている途中でもリアルタイムに音が変化します。
3. 繰り返したい開始位置で「Aを設定」、終了位置で「Bを設定」を押すと、A〜Bの区間ループが始まります。🔁ボタンを押すとループのオン・オフを切り替えられます（オンのときはボタンが紫色になります）。
4. 「設定をリセット」を押すと、キーが0半音に戻り、ループ区間が解除されます。「キー変更」スイッチをオフにすると、加工していない通常の音声に戻ります。

### ご利用上の注意点
- 拡張機能の画面（ポップアップ）を閉じても、キー変更やループの処理はそのまま続きます。
- 音声のキー変更を同時に使えるのは1つのタブだけです。
- ループ設定は、ページを再読み込み（リロード）すると解除されます。
- キー変更の途中で同じタブから別のページへ移動した場合は、必要に応じて処理を停止してください。

## 仕組みと制限事項（シンプルな作りについて）

この拡張機能は、プログラムをシンプルに保つため、以下のような仕様になっています。

- **音質の変化について**：再生速度を変えずにキーだけを変えるため、音声をわずかに遅らせて（約60ミリ秒以内）重ね合わせる簡易的な仕組み（AudioWorklet）を使っています。そのため、特にキーを大きく変えたときは、音が少し揺れたり、にじんだりして聞こえることがあります。
- **キー変更の対象**：Webページ内の動画だけでなく、通知音や同じタブ内の別プレーヤーの音など、そのタブから出る音全体にかかります。
- **ループが動く場所**：メインページ（メインフレーム）内にある一般的なHTML動画・音声が対象で、再生中の要素を優先して操作します（場合によっては本編ではなく広告動画などが選ばれることもあります）。ページ内に埋め込まれた別枠（iframe）の動画、特殊な仕組みのWebプレーヤー、著作権で保護された音声、Chromeの設定画面などでは対象外となり、動かないことがあります。
- **ループの精度**：約0.05秒（50ミリ秒）ごとに再生位置をチェックしてA地点へ戻しています。プロ仕様の編集ソフトのような厳密なタイミング合わせではなく、シークバーで再生位置を動かせる一般的な動画向けです。ライブ配信などでは機能に制限があります。
- **含まれていない機能**：イコライザー（EQ）、ボーカル除去、声質調整（フォルマント）、お気に入り区間の保存、アカウント機能、設定の自動保存などはありません。

## ファイルの構成

フォルダーは画像を置く `icons` だけです。プログラムのファイルはすべて一番上の階層に並んでいます。追加の設定ファイルや変換作業（ビルド）は不要です。

| ファイル | 役割 |
| --- | --- |
| `manifest.json` | 拡張機能の名前、使う権限、最初に動かすファイルなどをChromeに伝える「設計図」です |
| `popup.html` | 拡張機能を開いたときの画面（スイッチやボタンなどの部品）を作ります |
| `popup.css` | 画面の部品の色・大きさ・余白などの見た目を整えます |
| `popup.js` | スイッチやボタンが操作されたときの動きを受け持ちます |
| `content.js` | 開いているWebページの動画に働きかけ、A〜Bの区間を繰り返します |
| `background.js` | Chromeからタブの音声を受け取るための「合言葉（ID）」を受け取る裏方です |
| `offscreen.html` | 音声処理を裏側でずっと動かし続けるための、画面には見えないページです |
| `offscreen.js` | タブの音声を受け取り、キー変更の計算機を通してスピーカーにつなぎます |
| `pitch-worklet.js` | 音声データを計算して、実際に音の高さを変える専門のプログラムです |
